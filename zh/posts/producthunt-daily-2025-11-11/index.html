24. 8n Docs#

标语：生成 n8n 工作流的文档

n8n 工作流概述#

n8n 是一个开源的自动化工具，它允许用户通过创建工作流来连接不同的应用和服务。工作流由一系列节点组成，每个节点执行特定的操作，如获取数据、处理信息或发送通知。

创建工作流步骤#

  1. 打开 n8n: 启动 n8n 应用程序，进入工作流编辑界面。

  2. 添加节点:

    • 点击“+”按钮，选择你需要的节点类型，比如 HTTP 请求、数据库操作等。
    • 配置节点的具体参数，如请求的 URL、数据库连接信息等。

  3. 连接节点:

    • 拖动节点之间的连线，定义数据流向。确保前一个节点的输出可以作为后一个节点的输入。

  4. 设置触发器:

    • 选择一个触发器节点，例如定时触发或 Webhook 触发，来启动工作流。

  5. 测试工作流:

    • 点击“运行”按钮，测试工作流的每个节点，确保数据处理顺利。

  6. 保存工作流:

    • 完成后，记得保存工作流，以便后续使用或修改。

重要概念#

  • 节点: 工作流中的基本构建块，每个节点执行特定的功能。
  • 数据流: 节点之间传递的数据，确保信息能够顺利从一个节点流向另一个节点。
  • 触发器: 工作流的起点，定义何时启动整个工作流。

文档示例#

示例工作流：自动发送欢迎邮件#

  1. 触发器: 使用 Webhook 触发器，接收用户注册请求。
  2. 节点1 - 获取用户信息: 从 Webhook 获取用户的电子邮件和姓名。
  3. 节点2 - 发送电子邮件: 配置 SMTP 节点，使用获取的用户信息发送欢迎邮件。
  4. 连接: 将 Webhook 连接到第一个节点，再将第一个节点连接到发送邮件节点。
